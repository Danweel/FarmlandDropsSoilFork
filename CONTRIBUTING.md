# Contributing to FarmlandDropsSoilFork

Thanks for wanting to build from source! Here's what you need to know:

## Build Setup

1. Clone the repo
2. Open `.csproj` in your editor
3. Update the `HintPath` entries to match your system (see README for paths)
4. Run `dotnet build`

## Common Issues

### "Cannot find VintagestoryAPI.dll"
The path in `.csproj` points to my installation. Update it to yours.

### "References not resolving"
Make sure Vintage Story is installed and you're pointing to the correct version folder.

## Questions?
Open an issue and I'll help when I can!
